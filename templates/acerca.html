Proyecto municipal N.º 30

Acerca del proyecto

La Municipalidad necesita digitalizar la gestión de incidencias urbanas para centralizar la información, facilitar el seguimiento de operaciones, mantener datos históricos consistentes y coordinar a ciudadanos y gestores municipales.

El sistema integra las tres etapas acumulativas de la asignatura: estructura base y vista pública (Evaluación 1), modelo ORM en MySQL y API REST con Django REST Framework (Evaluación 2), y CRUD web completo mediante Vistas Basadas en Clases (CBV) nativas de Django y formularios ModelForm con widgets personalizados (Evaluación 3).
